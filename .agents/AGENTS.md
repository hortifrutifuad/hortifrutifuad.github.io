# Regras do Projeto (Hortifruti Fuad)

Este é o **Case Zero (Portfólio)** do usuário.

## Diretrizes de Desenvolvimento para este Projeto:
1. **Qualidade de Portfólio:** Todo código gerado aqui (`index.html`, automações n8n, scripts) deve seguir os mais altos padrões de legibilidade, indentação e comentários, pois servirá como demonstração técnica para potenciais clientes.
2. **Abordagem "Local Business Booster":** Este projeto valida a arquitetura de "Site Estático Gratuito (GitHub Pages) + WhatsApp Bot (n8n)". As soluções devem focar em conversão via WhatsApp e custo zero de hospedagem.
3. **Escalabilidade:** Mantenha a arquitetura modular para que possamos extrair trechos de código facilmente para outros clientes (ex: padarias, oficinas).
4. **Acompanhamento (Kanban/Checklist):** Sempre mantenha um checklist/Kanban de progresso estruturado no final do `README.md` para facilitar o acompanhamento e visualização das fases concluídas, em andamento e futuras.
